# Licensing rules

Modular A/V is MIT, with Affid as the copyright holder. It grew out of
work on a fork of LiveKit AVClient (`bekriebel/fvtt-module-avclient-livekit`),
which is under the Hippocratic License 2.1. That licence stays attached
to its code even inside modified versions, so none of that code may be
here. This is not legal advice; these are the rules the project keeps.

1. **No upstream code.** Nothing is copied from LiveKit AVClient or from
   contributions made to it under the Hippocratic License (among them the
   noise suppressor filter of its PR #107), not even in part. Reading
   them to understand behaviour is fine; the code here is written from
   this project's own design.
2. **Own names.** No module id, title, README text or image reuses
   `avclient-livekit` or "LiveKit AVClient", except to say what Modular
   A/V replaces or conflicts with.
3. **Nothing vendored.** Third-party code comes from its npm package and
   its files are copied at build time (`tools/assets`), so a changed file
   can't slip in.
4. **Every module zip holds only MIT, ISC, BSD or Apache-2.0 code**
   (`ALLOWED_LICENSES` in `tools/notices/notices.ts`), and the build
   refuses anything else. Each module lists what it ships in
   its own `THIRD-PARTY-NOTICES.md`, generated by the build.
5. **Krisp is the exception, kept apart.** `@livekit/krisp-noise-filter`
   isn't open source, so it lives in a module of its own,
   `modular-av-livekit-krisp`, which is held back from releases until
   LiveKit confirms in writing that a Foundry module may load it for its
   users ([ROADMAP.md](ROADMAP.md)).
6. Foundry's own licence for module developers applies to every module.
